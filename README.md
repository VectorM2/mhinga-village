# Mhinga — Community Platform

> Our Home. Our Community. Our Future.

The digital home of Mhinga, Limpopo: services, schools, bursaries and jobs, notices, news, events, step-by-step guides, a business directory and a CMS-style admin dashboard.

Built with **Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS v4 · shadcn-style components (Radix + CVA) · Lucide icons**. Runs entirely on typed mock data today and is structured to switch to **Supabase** without touching the UI.

## Getting started

```bash
npm install
cp .env.example .env.local   # optional — the site runs without it
npm run dev                  # http://localhost:3000
npm run build && npm start   # production build
```

No API keys are needed to run locally (maps use OpenStreetMap links; fonts are self-hosted via Fontsource).

## Deploying (Vercel — free, ~5 minutes)

1. Create a GitHub repository and push this folder (`git init && git add . && git commit -m "Mhinga" && git push`).
2. Go to vercel.com → **Add New → Project** → import the repo. Framework is detected automatically; no settings needed.
3. Optional: add `NEXT_PUBLIC_SITE_URL` (your Vercel URL or mhinga.co.za) under **Environment Variables**.
4. Click **Deploy**. You get a live `*.vercel.app` link; a custom domain can be added later under **Domains**.

Alternative without GitHub: `npm i -g vercel` then run `vercel --prod` inside this folder.

## Content & trust rules

- **Nothing official is invented.** Phone numbers, hours, procedures and school details that could not be verified are shown as *“Information to be confirmed”*.
- Only the three national emergency numbers (10111, 10177, 112) are marked **✓ Verified**. Everything else shows **To be confirmed** until an administrator marks it verified in `/admin/services`, `/admin/schools` etc.
- School names come from public school listings; contact details are left blank until confirmed.
- News articles are practical, evergreen explainers. Notices, events, local opportunities, businesses and stories are clearly labelled **Sample** until replaced.
- The footer states the site is an independent community website. Set `isOfficial` in `src/lib/site.ts` only if a recognised authority formally operates it.

## Replacing placeholder images

Swap the entries in `images` in `src/lib/site.ts` for real photos (put them in `public/images/` or Supabase Storage — the `*.supabase.co` host is already allowed in `next.config.ts`).

## Connecting Supabase

1. Create a project and run `supabase/schema.sql` in the SQL editor.
2. Create storage buckets: `gallery` (public), `report-photos` (private), `business-logos` (public).
3. Add `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_ANON_KEY` to `.env.local`.
4. Replace the bodies of the functions in `src/lib/data/index.ts` with queries using `getSupabase()` — signatures stay the same so pages don't change.
5. Replace the `TODO(supabase)` blocks in `src/lib/actions.ts` with inserts.
6. Add `@supabase/ssr`, a login page and a role check in `src/app/admin/layout.tsx` (roles: `super_admin`, `editor`, `community_manager`; RLS policies already exist).
7. In production, remove `NEXT_PUBLIC_FIXED_NOW` (it pins "today" to 7 Oct 2026 so mock deadlines/events stay meaningful).

## Map

Set confirmed coordinates in `siteConfig.map.center` to switch the Explore map from an illustrated preview to a live OpenStreetMap embed. Mapbox/Google can be added in `src/components/shared/map-view.tsx`.
